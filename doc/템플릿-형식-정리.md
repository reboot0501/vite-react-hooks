React + TypeScript에서 가장 기본적인 `export default` JSX 컴포넌트 템플릿은 다음과 같습니다.

```tsx
const Example = () => {
    return (
        <div>
            Hello React
        </div>
    )
}

export default Example
```

### 조금 더 일반적인 기본 템플릿

```tsx
interface ExampleProps {
    title?: string
}

const Example = ({ title = 'Hello React' }: ExampleProps) => {
    return (
        <div>
            <h1>{title}</h1>
        </div>
    )
}

export default Example
```

### Props가 없는 컴포넌트라면

```tsx
const Example = () => {
    return (
        <div>
            Example
        </div>
    )
}

export default Example
```

또는 **함수 선언 방식**을 선호한다면:

```tsx
function Example() {
    return (
        <div>
            Example
        </div>
    )
}

export default Example
```

개인적으로 **React + TypeScript + Tailwind + shadcn/ui** 구조라면 첫 번째 형태를 기본 템플릿으로 두고, Props가 필요할 때만 `interface`를 추가하는 방식이 깔끔합니다.

네. 이 코드는 **named export(이름 있는 export)** 방식입니다.

```tsx
export function Example() {
    return (
        <div>
            Example
        </div>
    )
}
```

### `export default`와 차이

| 방식            | 선언                                | import                               | 비고                          |
| -------------- | ----------------------------------- | ------------------------------------ | ----------------------------- |
| Named export   | `export function Example()`         | `import { Example } from './Example'` | 중괄호 필수, 이름 필수, 이름 변경 as 로 가능 |
| Default export | `export default function Example()` | `import Example from './Example'`     | 이름 자유                     |

#### 1. Named export

```tsx
// Example.tsx
export function Example() {
    return <div>Example</div>
}
```

사용: 반드시 중괄호, import시 파일명과 export 와 동일한 이름으로 import

```tsx
import { Example } from './Example'
```

**이름이 반드시 `Example`이어야 합니다.**

---

#### 2. Default export

```tsx
// Example.tsx
export default function Example() {
    return <div>Example</div>
}
```

사용: 중괄호 불필요, 파일명과 다른 이름으로 import 가능

```tsx
import Example from './Example'
```

Default export는 import할 때 이름을 바꿀 수도 있습니다.

```tsx
import MyExample from './Example'
```

### React + TypeScript에서 자주 쓰는 형태

```tsx
export function Example() {
    return (
        <div>
            Example
        </div>
    )
}
```

이 형태는 **여러 컴포넌트를 하나의 파일에서 export할 때** 특히 편합니다.

```tsx
// Layout.tsx
export function Header() {
    return <header>Header</header>
}

export function Footer() {
    return <footer>Footer</footer>
}
```

```tsx
// App.tsx - Header, Footer 두 개의 컴포넌트를 import
import { Header, Footer } from './Layout'
```

즉, **`export function Example()` 자체가 React 컴포넌트로서 완전히 정상적인 TypeScript JSX 문법**입니다. `default`가 없을 뿐입니다.
